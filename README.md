# Math Monsters

Math Monsters is a browser-based math game built with Phaser, Vite, and TypeScript.

## Prerequisites

- Node.js 20 or newer
- npm (comes with Node.js)

## Install dependencies

From the project root:

```bash
npm install
```

## Run locally (development)

Start the local development server:

```bash
npm run dev
```

Vite will print a local URL (typically `http://localhost:5173`) where you can open the game in your browser.

## Build for production

Create a production build in the `dist/` folder:

```bash
npm run build
```

## Preview the production build locally

Serve the production build locally:

```bash
npm run preview
```

Open the URL shown in the terminal to verify the built app.

## Run tests

Run automated tests once:

```bash
npm run test
```

## Project scripts

- `npm run dev`: start Vite development server
- `npm run build`: run TypeScript checks and create production build
- `npm run preview`: serve the production build from `dist/`
- `npm run test`: run Vitest test suite
